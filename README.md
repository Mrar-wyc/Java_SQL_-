# 超市商品管理系统 


## 一、项目概述

### 1.1 项目背景
随着中小型超市的规模化发展，手动记录商品信息、库存变动及销售数据的传统方式已难以满足高效管理需求。本系统旨在通过数字化手段，实现商品全生命周期的规范化管理，降低人工操作误差，提升运营效率。


### 1.2 项目简介
本项目是基于 **Java Swing + MySQL** 开发的桌面端超市商品管理系统，采用分层架构（视图层、控制器层、数据访问层、模型层）设计，支持商品从入库到销售的全流程管理，包含基础信息维护、库存监控、销售记录、数据统计等核心功能，适配中小型超市的日常运营场景。


### 1.3 技术栈
| 技术/工具 | 说明 | 选型优势 |
|----------|------|----------|
| **Java** | 核心开发语言 | 跨平台性强， Swing 组件适合快速构建桌面应用 |
| **Swing** | 桌面 GUI 库 | 内置丰富组件，无需额外依赖，原生适配系统界面 |
| **MySQL** | 关系型数据库 | 轻量稳定，支持事务管理，适合存储结构化商品数据 |
| **JDBC** | 数据库连接技术 | 原生支持 MySQL 交互，便于实现数据持久化 |
| **Maven** | 项目构建工具 | 自动化管理依赖（如 MySQL 驱动），简化部署流程 |

## 三、项目架构与目录结构

### 3.1 架构设计
采用经典的 **MVC 分层架构**，职责划分清晰：
- **Model（模型层）**：封装业务数据（如商品、用户、分类等实体），对应数据库表结构
- **View（视图层）**：实现用户界面（登录页、主页面等），负责数据展示与用户交互
- **Controller（控制器层）**：协调视图与模型，处理业务逻辑（如登录验证、商品新增）
- **DAO（数据访问层）**：提供数据库交互接口，封装 SQL 操作
- **Util（工具层）**：封装通用功能（如数据库连接、文件操作）

## 四、数据库设计

### 4.1 核心表结构
系统采用规范化设计，共包含 10 张表，核心表如下：

| 表名 | 功能 | 核心字段 |
|------|------|----------|
| `sys_user` | 系统用户（管理员/操作员） | `user_id`（主键）、`username`、`password`、`role_id`（关联角色） |
| `product` | 商品信息 | `product_id`（主键）、`product_name`、`category_id`（分类）、`price`（价格）、`stock`（库存）等 |
| `product_category` | 商品分类 | `category_id`（主键）、`category_name`、`parent_id`（父分类，支持多级分类） |
| `sale_order` | 销售单主表 | `order_id`（主键）、`user_id`（操作员）、`sale_time`（销售时间）、`total_amount`（总金额） |
| `stock_log` | 库存变动日志 | `log_id`（主键）、`product_id`、`change_quantity`（变动量）、`before_stock`（变动前）、`after_stock`（变动后） |


### 4.2 设计亮点
- **外键关联**：核心表通过外键保持数据一致性（如 `product.category_id` 关联 `product_category.category_id`）
- **事务支持**：销售出库操作通过事务确保“扣减库存+记录日志”原子性
- **编码规范**：所有表采用 `utf8mb4` 编码，支持中文及特殊字符
- **日志溯源**：`stock_log` 记录每一次库存变动，便于追踪操作历史


## 五、核心功能详解

### 5.1 基础功能
#### 5.1.1 登录验证
- 验证 `sys_user` 表中的账号密码，仅有效用户（`is_valid=1`）可登录
- 区分角色（管理员/操作员），后续功能权限按需展示


#### 5.1.2 商品管理
- **新增**：通过表单录入商品信息，分类/供应商/仓库通过下拉框选择（避免手动输入错误）
- **修改**：选中表格中商品，修改后校验数据格式（如价格必须为数字）
- **删除**：支持单个商品删除，管理员专有权限
- **查询**：按名称/分类/条形码模糊搜索，结果实时展示在表格


### 5.2 高级功能
#### 5.2.1 多条件筛选
- 支持组合条件：分类+供应商+价格区间+库存区间+上架状态
- 界面采用 `GridBagLayout` 分组布局，筛选条件清晰易操作


#### 5.2.2 销售出库
- 流程：选择商品 → 输入销售数量/单价 → 系统自动计算小计 → 确认后扣减库存
- 事务保障：若库存扣减或日志记录失败，自动回滚操作，确保数据一致
- 记录：同步生成 `sale_order`（销售单）和 `sale_item`（销售明细）


#### 5.2.3 库存预警
- 支持自定义阈值（如库存＜10时预警）
- 一键查询低于阈值的商品，结果高亮显示，便于及时补货


#### 5.2.4 数据导出
- 将商品数据导出为 TXT 格式，自动保存到系统桌面（兼容 Windows/Mac/Linux）
- 导出内容包含完整商品信息（名称/价格/库存/保质期等）


## 六、部署与运行步骤

### 6.1 准备数据库
1. 打开 MySQL 客户端（Navicat/MySQL Workbench），执行以下命令创建数据库：
   ```sql
   CREATE DATABASE IF NOT EXISTS supermarket_db CHARACTER SET utf8mb4;
   ```
2. 切换到 `supermarket_db` 数据库，执行 `src/SQL/构建.sql` 创建表结构
3. 执行 `src/SQL/插入基础字典数据.sql` 初始化角色、分类等基础数据
4. （可选）执行 `src/SQL/插入商品测试数据.sql` 添加测试商品


### 6.2 配置数据库连接
1. 打开 `com.sms.util.DbUtil.java`，修改连接参数：
   ```java
   private static final String URL = "jdbc:mysql://localhost:3306/supermarket_db?useSSL=false&serverTimezone=UTC";
   private static final String USER = "root"; // 你的MySQL用户名
   private static final String PASSWORD = "123456"; // 你的MySQL密码
   ```
   - 若使用 MySQL 8.0+，`serverTimezone=UTC` 必须添加，否则可能出现时区错误


### 6.3 导入项目并运行
1. 克隆/下载项目源码，导入 IntelliJ IDEA/Eclipse
2. **导入依赖**：
   - 方式1（Maven）：IDE 自动识别 `pom.xml`，下载 `mysql-connector-java 8.0.33`
   - 方式2（手动）：将 `mysql-connector-java-8.0.28.jar` 放入 `lib` 目录并添加到构建路径
3. 运行 `src/main/java/Main.java`，启动程序
4. 初始账号登录：`admin/123456`（管理员权限）


## 七、使用指南

### 7.1 主界面布局
- **顶部区域**：左侧为搜索框（支持模糊查询），右侧为功能按钮（新增/修改/销售等）
- **中间区域**：商品数据表格（展示所有字段，支持排序）
- **操作流程**：登录 → （新增/查询）商品 → 销售出库 → （可选）导出数据/查看预警


### 7.2 常见操作示例
#### 示例1：新增商品
1. 点击“新增商品”按钮，弹出表单
2. 填写商品名称、价格等信息，分类/供应商/仓库从下拉框选择
3. 点击“确认”，系统自动校验数据格式（如价格必须为数字），校验通过后保存


#### 示例2：销售商品
1. 在表格中选中待销售商品
2. 点击“销售出库”按钮，输入销售数量和单价
3. 系统自动计算小计金额，确认后扣减对应库存，并生成销售记录和库存日志


## 八、注意事项

1. **数据库兼容性**：
   - MySQL 8.0+ 需使用 8.x 版本驱动，且 URL 必须添加 `serverTimezone=UTC`
   - MySQL 5.7 可使用 5.x 驱动，URL 无需时区配置

2. **数据校验**：
   - 新增/修改商品时，“价格/库存/保质期”必须为数字，否则提示输入错误
   - 条形码为唯一标识，不可重复添加

3. **事务与数据安全**：
   - 销售出库操作依赖数据库事务，确保库存扣减和日志记录同时成功或失败
   - 建议定期备份 `supermarket_db` 数据库，避免数据丢失

4. **路径适配**：
   - 商品导出功能通过 `FileSystemView` 获取系统桌面路径，无需手动修改
   - 若导出失败，检查当前用户对桌面目录是否有写入权限


## 九、常见问题解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 登录提示“Table 'supermarket_db.admin' doesn't exist” | 代码查询旧表 `admin`，未更新为新表 `sys_user` | 检查 `ProductDao` 中登录方法，确认 SQL 语句查询 `sys_user` 表 |
| 导出商品提示“找不到指定路径” | 硬编码桌面路径不兼容系统 | 确保使用 `FileSystemView.getFileSystemView().getHomeDirectory()` 获取桌面路径 |
| 多条件筛选界面混乱 | 布局未分组，组件重叠 | 使用 `GridBagLayout` 重构筛选面板，添加标题边框区分条件组 |
| 数据库连接失败 | 连接参数错误或驱动未导入 | 检查 `DbUtil.java` 中 URL/用户名/密码；确认驱动包已添加到项目 |


## 十、扩展建议

1. **安全增强**：
   - 密码加密：当前密码明文存储，可集成 MD5/SHA256 加密（推荐 BCrypt 算法）
   - 操作日志：新增 `operate_log` 表，记录用户登录/关键操作时间

2. **功能扩展**：
   - 权限控制：基于 `user_role` 表实现细粒度权限（管理员可删改，操作员仅查询/销售）
   - 报表统计：使用 JFreeChart 生成销售趋势图、库存占比图，支持按时间/分类筛选
   - 批量操作：支持 Excel 批量导入商品、批量修改价格/库存阈值

3. **体验优化**：
   - 界面美化：使用 FlatLaf 等主题库优化 Swing 界面样式
   - 快捷键：为常用操作（如搜索/新增）添加快捷键（如 Ctrl+F/Ctrl+N）
